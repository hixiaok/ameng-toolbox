关于

Iris —— 面向 Android 设备的多功能工具链。

核心库与界面完全分离：本页面只是 iris.core 的一个前端， CLI（iris doctor / super / gpt）用的是同一套代码。

  • GPL-3.0，参考 VioletToolBox 的设计与格式知识独立实现
  • 不打包任何第三方二进制
  • 所有解析在本地完成，不上传任何数据

服务端：Python 标准库 http.server，零第三方依赖。
