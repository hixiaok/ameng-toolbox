A梦工具箱把安卓调试、刷机、投屏、应用与文件管理收进一个原生 Windows 窗口：不用背命令，也不用在多个工具之间切换。内置 adb、fastboot 与 scrcpy，连上手机就能看到设备信息、装应用、刷分区、投屏和开终端。

一个窗口，覆盖常用操作

不来回切换命令行和多个工具。

📊

仪表盘

连接后自动读取型号、系统版本、SoC、分辨率、DPI、电量、存储与内存；支持截图、录屏、抓日志、无线调试和重启设备。

⚡

快捷指令

把常用 adb 操作做成按钮：重启到系统 / Recovery / Bootloader / Fastbootd、屏幕常亮、动画缩放、显示触摸、重启 ADB、打开设备管理器。

🧰

刷机 / Fastboot

按品牌把镜像刷进指定分区；小米 / 红米支持整包 flash_all 脚本；另有 Bootloader 解锁 / 回锁、双清、分区表读取与备份还原。

🔑

ROOT 辅助

检测 root 状态与管理器，备份 boot / init_boot / vbmeta，一键打开 Magisk / KernelSU；页面内附修补流程说明。

📺

投屏

内置官方 scrcpy 5.0.1，可选分辨率、码率、窗口置顶，不需要再单独下载。

💾

基带备份

modem / fsg / fsc / persist 等基带相关分区单独列出，支持备份到电脑和还原，改机前先留一份。

📦

应用 / 模块

全部 / 第三方应用列表，支持冻结、解冻、清数据、提取 APK、卸载和安装 APK；模块页可启停 Magisk / KernelSU 模块。

⌨️

终端

设备 adb shell 或本机 CMD 两种模式，支持 root 开关、历史记录、输出复制，方便临时排查问题。

安装与运行

三步开始。

1

下载并解压 / 安装

安装包双击运行；绿色版解压到任意目录。

2

允许管理员权限

程序需要管理员权限访问 adb / fastboot；未签名时 SmartScreen 选「更多信息 → 仍要运行」。

3

连接手机

手机开启 USB 调试并授权，打开软件即可看到设备。

刷机风险提示：解锁、回锁、双清、刷入分区都有风险，不同机型分区和脚本差异很大。工具只负责调用命令，刷错分区或脚本可能导致无法开机，请确认自己知道后果再操作。

A梦工具箱需要 root 吗？

不需要 root 也能使用设备信息、投屏、应用管理、文件传输等大部分功能；分区备份、修改系统分区等需要 root。

为什么需要管理员权限？

adb / fastboot 访问 USB 设备、安装驱动、写 Program Files 需要管理员权限。

支持 macOS / Linux 吗？

目前只有 Windows 桌面版，基于 WPF 与 .NET Framework 4.8。
