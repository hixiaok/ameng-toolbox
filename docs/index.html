一个窗口，覆盖常用操作

不来回切换命令行和多个工具。

📊

仪表盘

设备信息、电量 / 存储 / 内存、详细参数、截图、录屏、日志、无线调试。

⚡

快捷指令

重启到系统 / Recovery / Bootloader / Fastbootd、屏幕常亮、动画缩放、重启 ADB。

🧰

刷机 / Fastboot

单分区线刷、小米整包 flash_all、Bootloader 解锁 / 回锁、双清、分区备份还原。

🔑

ROOT 辅助

root 状态、备份 boot / init_boot / vbmeta、打开 Magisk / KernelSU。

📺

投屏

内置 scrcpy，分辨率、码率、窗口置顶，开箱即用。

💾

基带备份

modem / fsg / persist 等分区备份与还原，关键数据先留一份。

📦

应用 / 模块

冻结、解冻、清数据、提取 APK、安装 APK；Magisk / KernelSU 模块启停。

⌨️

终端

设备 adb shell 或本机 CMD，root 开关、历史记录。

安装与运行

三步开始。

1

下载并解压 / 安装

安装包双击运行；绿色版解压到任意目录。

2

允许管理员权限

程序需要管理员权限访问 adb / fastboot；未签名时 SmartScreen 选「更多信息 → 仍要运行」。

3

连接手机

手机开启 USB 调试并授权，打开软件即可看到设备。

刷机风险提示：解锁、回锁、双清、刷入分区都有风险，不同机型分区和脚本差异很大。工具只负责调用命令，刷错分区或脚本可能导致无法开机，请确认自己知道后果再操作。

A梦工具箱需要 root 吗？

不需要 root 也能使用设备信息、投屏、应用管理、文件传输等大部分功能；分区备份、修改系统分区等需要 root。

为什么需要管理员权限？

adb / fastboot 访问 USB 设备、安装驱动、写 Program Files 需要管理员权限。

支持 macOS / Linux 吗？

目前只有 Windows 桌面版，基于 WPF 与 .NET Framework 4.8。
